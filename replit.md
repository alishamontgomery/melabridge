# MelaBridge

An AI-native event planning platform — a unified workspace for hosts, planners, vendors, and venues. Built with TanStack Start (SSR React), Supabase, Stripe, and Tailwind CSS.

## Running the app

```bash
npm run dev
```

Starts the Vite dev server on **port 5000**. The workflow "Start application" is pre-configured and runs this automatically.

## Stack

- **Framework**: TanStack Start (TanStack Router + Vite SSR)
- **UI**: React 19, Radix UI, Tailwind CSS v4, shadcn/ui components
- **Backend/Auth**: Clerk authentication with Supabase (`SUPABASE_URL` + `SUPABASE_PUBLISHABLE_KEY`)
- **Payments**: Stripe (dev key in `.env.development` as `VITE_PAYMENTS_CLIENT_TOKEN`)
- **Email**: Resend through the Replit connector
- **Maps**: Direct Google Places API through the server-side `GOOGLE_PLACES_API_KEY`

## Environment secrets needed for full functionality

| Variable | Purpose |
|----------|---------|
| `STRIPE_SECRET_KEY` | Server-side Stripe operations (checkout, webhooks) |
| `GOOGLE_PLACES_API_KEY` | Server-side Google Places autocomplete, details, and vendor search |

The Supabase public keys are already checked in to `.env` and work out of the box. Google sign-in is intentionally disabled pending full OAuth verification.

## Audit fixes applied (July 2026)

### Navigation & interactions
- **Tasks**: Clicking a kanban card or list-row title opens a `TaskDetailDialog` (edit title, priority, status, due date). "Complete" remains a separate explicit button in the kanban view; checkbox in list view is a quick toggle only.
- **Guests**: RSVP summary stat cards (Attending / Maybe / Pending / Declined) are now clickable and filter the table below. Guest names open a `GuestDetailDialog` for full editing (name, email, phone, household, RSVP, plus-ones, meal choice, notes, delete).
- **Today's Brief**: Insight cards with `guests`, `budget`, `task`, `vendor`, `timeline` icons now navigate to the relevant page with an arrow indicator.
- **Vendors**: Vendor directory cards open a `VendorDetailDialog` showing description, location, price, and website.
- **Run sheet**: Was already correct — clicking the row title expands detail inline; separate icon buttons handle Complete / Delayed / Critical.
- **Budget**: Category cards were already clickable and line items already editable via `CategoryEditorDialog`.

### Role separation
- Personal/planner accounts show only `PLANNER_NAV`; vendor-only routes (`/vendor*`, `/vendor-portal`, `/vendor-settings`, `/vendor-profile-builder`) are guarded by `ROLE_EXCLUSIVE` in `AppShell` and redirect personal users to their dashboard.
- Role-based login redirects (Personal → `/dashboard`, Vendor → `/vendor`, Admin → `/admin`) already worked and are preserved.

### Stability & environment
- `pendingVerificationEmail` in `auth.tsx` is now persisted to `sessionStorage` (`melabridge.pending.verification`) so the correct signup email survives a page refresh and is cleared when the user successfully signs in.

### Mobile
- Removed `overflow-hidden` from `PageHeader` section so action buttons and long titles on narrow viewports are no longer clipped by the rounded container.
- Guest table columns (Phone, +1s, Meal) now hide on small screens with `sm:`/`md:` breakpoints to prevent horizontal overflow.

### Build health
- `npx tsc --noEmit` returns 0 errors.
