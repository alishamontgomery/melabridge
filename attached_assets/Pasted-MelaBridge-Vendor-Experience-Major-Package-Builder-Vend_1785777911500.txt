MelaBridge Vendor Experience - Major Package Builder & Vendor Template Redesign

The vendor package builder has improved, but it still feels like a pricing form rather than a professional storefront. This needs to become one of MelaBridge’s defining features because it’s where vendors sell their business and convince customers to book.

The goal is for vendors to feel like they’re creating a polished mini-website—not filling out paperwork.

⸻

Create Dynamic Package Builders by Vendor Category

Do not use one generic package builder for every business.

Instead, when a vendor selects their business category, dynamically load fields, templates, and suggestions designed specifically for that industry.

Each category should have fields that make sense for that business while still allowing complete customization.

Make Package Creation Fast

Reduce typing wherever possible.

Use:

* Toggle switches
* Checkboxes
* Multi-select chips
* Smart defaults
* AI suggestions
* Category templates
* Auto-complete
* Optional custom fields for anything unique

Typing should primarily be reserved for descriptions and unique selling points.

⸻

Improve the Package Builder

Allow vendors to:

* Create unlimited packages
* Duplicate packages
* Drag and reorder packages
* Feature a package
* Archive packages
* Preview packages exactly as customers will see them

The preview should resemble a polished storefront, not an admin form.

⸻

Rename Booking Rules

The wording still feels technical.

Remove the word “Buffer” everywhere in the platform.

Rename the section to:

Availability Preferences

or

Scheduling Preferences

Replace the fields with:

* Preparation Time Before Events
* Cleanup Time After Events
* Maximum Events Per Day
* Travel Time Between Events
* Vacation Mode
* Blocked Dates

These labels are much more intuitive for vendors.

⸻

Improve Weekly Availability

The current workflow is too slow because vendors must configure one day at a time.

Instead:

* Display Monday through Sunday on one screen.
* Allow copying one day’s schedule to weekdays or the entire week.
* Allow marking days as Closed with one tap.
* Support multiple availability windows in a single day.

⸻

Simplify Blocked Dates

The calendar should be the primary focus.

Instead of several empty fields, show the calendar immediately.

After selecting dates, prompt the vendor to choose:

* Vacation
* Personal
* Already Booked
* Holiday
* Maintenance
* Other

Then allow optional notes and save.

⸻

Overall Vision

The vendor experience should feel premium, modern, and effortless. A vendor should be able to complete their profile and build impressive packages in 10–15 minutes while feeling like they’ve created a professional storefront that showcases everything their business offers.

This should become one of MelaBridge’s strongest competitive advantages and be flexible enough to support virtually any event professional without feeling generic.
